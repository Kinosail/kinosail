# Owner access

The Owner configures libraries, providers, language, and maintenance. Use a unique password and complete required strong authentication. Keep provider credentials and write access restricted to trusted administrators.

Household viewing permissions are configured in Kinosail Player. A Player Viewer Profile does not automatically authorize administration of an independent Subtitles Server.

See [secure access]({{ '/owner-guide/security/' | relative_url }}) and [sign-in troubleshooting]({{ '/troubleshooting/sign-in-and-access/' | relative_url }}).
