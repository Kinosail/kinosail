# Choose subtitle work

Use wanted items to find gaps in your preferred subtitle language. Limit the media folders in setup if automation should cover only part of your library. Check one result before fetching a larger batch.

Player playlists and collections organize media playback; they are not the Subtitles batch-selection contract. The Subtitles dashboard handles up to ten wanted items per batch, and the HTTP API accepts a validated maximum of 50.

See [subtitle management]({{ '/user-guide/' | relative_url }}) and [API workflows]({{ '/developer-guide/api-workflows/' | relative_url }}).
