# Use sidecars with your media player

Subtitles saves validated files next to your videos. Point Kinosail Player or another sidecar-aware player at the same media tree and rescan/refresh there if needed.

Keep the Subtitles media mount writable and Player's mount read-only. Each app needs its own state volume. Verify language and timing in the viewing app before removing any original recovery copy.

Household sharing and synchronized Watch Rooms belong to Player. Subtitles does not need to expose media publicly to find or save subtitles.

See [sidecar compatibility]({{ '/reference/media-compatibility/' | relative_url }}).
