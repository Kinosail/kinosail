# Optional Supporter badges

Kinosail Subtitles keeps every core feature free. Support is voluntary. A Polar purchase provides a key for a badge, not access to subtitle search or saving.

Choose [monthly support](https://buy.polar.sh/polar_cl_HTsVz4n50S840QL5zKCZ0yTZe6HpVfHqagCtQ1LZ6sN) for a Living Standard or [one-time support](https://buy.polar.sh/polar_cl_Aec8B5u63m6Wr6l6bfZNMS6dmYRyM4jAMAzxQ28S4b3) for a Patron Order. Each family has ten levels. The checkout shows the current price before an order.

## Activate on your Server

1. Complete the Polar checkout and keep the key it gives you private.
2. Sign in as Owner on your Kinosail Subtitles Server.
3. Open **Settings**, select **Open supporter badges**, enter the key, and select **Activate or refresh badge**.
4. Check **Your badge case** for the awarded family, level, and active dates.

The Server sends the key, the `kino-subtitles` app ID, and a random installation mark to the Kinosail Supporter service. It stores the signed result, not the key or payment details. The Server verifies the signature with its pinned production public key and can display an existing badge when the service is unavailable.

Monthly Living Standards show their active period. One-time Patron Orders remain earned. A Complete Fleet key can cover included Kinosail apps; the signed collection record determines which apps and edition apply. Each Server still activates its own badge.

If a key is rejected, check that you entered the complete key and chose a Subtitles or Complete Fleet product. Check the activation limit in your Polar order. Use the [support page](https://github.com/Kinosail/kinosail/blob/main/SUPPORT.md) if the order and badge disagree. Do not post a key in an issue or screenshot.
