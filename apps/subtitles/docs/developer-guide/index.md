# Build with Subtitles

Use the versioned HTTP API for integrations and the shared application operations for repository work. Keep providers, credentials, and filesystem targets behind Server validation.

- [API quickstart]({{ '/developer-guide/api-quickstart/' | relative_url }})
- [Fetch and maintenance workflows]({{ '/developer-guide/api-workflows/' | relative_url }})
- [API route reference]({{ '/reference/api/' | relative_url }})
- [MCP boundaries]({{ '/developer-guide/mcp/' | relative_url }})

The Server's live `/api/v1/openapi.json` is authoritative for that installed version. Retained Player internals do not establish that a Player workflow is part of the Subtitles product.
