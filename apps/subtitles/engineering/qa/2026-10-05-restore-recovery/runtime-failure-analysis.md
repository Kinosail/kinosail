- A delivered Restore 204 does not prove delivery of the held inspection body.
- Fixture-only completion, 202 or HTTP 500 cannot establish a truthful UI outcome or file rollback.
- Cancelled requests cannot be counted as delivered old-response coverage.
- Missing request terminal, expired hold, forced fixture kill or failed checked close makes acceptance incomplete.

- A symlink, nonregular file, unstable descriptor, close error or bounded-read overflow blocks its binding.

- Installed package or browser executable drift must invalidate the compiled and browser result.
- Duplicate JSON keys, nonfinite numbers, wrong types or extra nested fields can forge acceptance.
