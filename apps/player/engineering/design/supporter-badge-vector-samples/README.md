# Supporter badge vector samples

These ten concept sheets compare vector-only badge directions. Each sheet shows levels 1 through 10, for 100 samples.

The artwork uses SVG paths, shapes, gradients, clips, and line patterns. It contains no raster image, embedded data, or remote asset.

Open `index.html` to compare all sets. Open an SVG file to inspect or edit one set.

Run these commands after a geometry change:

```sh
node generate.mjs
node verify.mjs
```

The live badge files remain unchanged until one direction is selected.
