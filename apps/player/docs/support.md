# Kinosail Player support

Kinosail Player is free. It plays media from a server that you or your household run. Kinosail does not run your server and cannot see your library or account.

## Get help

1. Check [Frequently asked questions]({{ '/faq/' | relative_url }}) and [Troubleshooting]({{ '/troubleshooting/' | relative_url }}).
2. For sign-in problems, see [Sign-in and access]({{ '/troubleshooting/sign-in-and-access/' | relative_url }}).
3. For playback problems, see [Playback]({{ '/troubleshooting/playback/' | relative_url }}).
4. If you still need help, [open a support request](https://github.com/Kinosail/kinosail/issues/new/choose) on GitHub.

In a support request, include the app (iPhone, iPad, Apple TV, Apple Watch, or web), the app version, the server type (Kinosail, Jellyfin, Emby, or Plex), what you expected, and what happened. Do not post passwords, access tokens, private server addresses, or media details in a public request.

## Server accounts and data

The Owner of your server manages your Profile, sessions, and viewing data. To remove that data, contact the Owner of your server. To remove data from your device, sign out in Settings or delete the app. The [privacy policy]({{ '/privacy/' | relative_url }}) has the details.

## Security reports

Do not report security issues in a public request. Follow the [security policy](https://github.com/Kinosail/kinosail/blob/main/SECURITY.md).
