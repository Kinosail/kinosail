# Player phone E2E

This package drives the actual Swift iOS and Kotlin Android phone apps with deterministic semantic actions. It uses the existing disposable Go fixture and public `/api/v1` operations. The pinned SDK requires no AI model, provider key, testerarmy account, hosted device plan, or artifact upload service.

Run this lane on an isolated GitHub Actions runner using `.github/workflows/native-phone-e2e.yml`. That workflow is callable and supports manual runs. It compiles the Go Server and native app at the checked-out revision, creates one new simulator or emulator, and deletes only its owned device. Before iOS creation, it records the run name, runtime, device type and an inventory proving that name is absent. Recovery requires one exact match; ambiguity prevents publication. `python3 hosted.py ios` and `python3 hosted.py android` reject local execution. The iOS lane requires the repository's `xcode-27` runner, Xcode 27.1 beta, an installed iOS 27 runtime and FFmpeg. It does not download a simulator runtime. Android uses Java 17, SDK 37 for compilation and an API 36 Google APIs x86_64 emulator with KVM.

Use Node 26.8.2 and run `npm ci --ignore-scripts --no-audit --no-fund`. Run `npm run typecheck` before native builds. TypeScript 7.0.2 checks SDK calls and configuration with strict types and no output. NodeNext and ES2022 match the harness modules. Existing JavaScript helpers and dependency declarations are not checked (`checkJs: false`, `skipLibCheck: true`). Node and PNG declarations are pinned. Run `npm test` for the harness privacy, HTTP, input and lifecycle contracts. Package versions and integrity hashes are committed in `package-lock.json`.

The native journey enters the fixture Server address, reads the real dynamic approval code, and approves it through a synthetic Owner with confirmed MFA, a session cookie and CSRF protection. It opens the populated movie library, checks changing colored decoded video frames and the native media clock, pauses and closes playback, then verifies public partial progress remains unwatched. Relaunch must restore the approved connection and retain that progress. iOS uses `127.0.0.1`; Android uses `10.0.2.2`. Relative media and artwork stay on the entered Server host. The fixture wrapper rejects an occupied fixed port before starting the Go process. There is one worker and no retry.

The SDK captures screenshots and semantic text on failure even with tracing off. Ordinary approval codes and approval QR images are not automatically secret-masked. A private `0600` sidecar records dynamic codes and synthetic credentials. Only `publish.mjs` can produce upload candidates. It first requires completed device cleanup, validates the owned output tree, redacts text, omits every SDK screenshot, semantic dump, trace, video and archive, removes raw output, then rebuilds the artifact hashes. A missing or unsafe sidecar, unsafe path or incomplete cleanup prevents upload. Both failed and successful native runs retain their original result in the sanitized receipt. The workflow uploads only `.e2e/published` after the privacy step succeeds. If cleanup or privacy fails, a separate `.e2e-rejection` artifact records only validated GitHub revision, run, job and step outcomes. It never reads rejected private output and retains a failure result. Never upload `.e2e`, the SDK output tree or device state directly.

A receipt records the revision, source manifest, Server and app hashes, command, synthetic test data, device/runtime/build environment, result and cleanup. `SHA256SUMS` covers the final sanitized files. The screenshots are analyzed locally for decoding evidence and then removed; they are not publication artifacts.

This integration is a draft until the hosted lanes pass. SDK discovery and harness contract tests establish configuration and privacy behavior only. They do not establish native builds, simulator/emulator runtime success, physical-device behavior, tvOS/watchOS, casting, external providers, container publication or deployment. Player is the only app with phone clients; Subtitles has no native target here.
