## Failure paths and intended repair

- Go renders canonical watch links and a safe Library fallback. The global `Referrer-Policy: no-referrer` prevents a Referer-based return repair. Watch query parameters would violate the preserved canonical-link contract. Add an escaped Go marker and localized destination labels to the existing Back action.
- Store one bounded return record in this tab's session storage, with the rendered Viewer Profile, current root browse URL, canonical departing action, loaded card count and finite scroll coordinates. Capture the URL at departure, after any live HTMX search. Do not cache HTML, change browser history, store in local storage or carry state across profiles.
- Treat saved state as untrusted. Reject external URLs, non-root routes, unknown or duplicate query fields, invalid bounds, mismatched profiles or destinations, oversized records and excessive extents. Go `catalog.ParseBrowse` remains the public authority. Existing authentication, TLS and no-referrer safeguards remain exact.
- Restore missing cards through the existing real Go continuation links and validated fragment parser. Preserve canonical identity validation, per-group deduplication, stale-generation cancellation and accessible Load more/Retry fallback. A failed or exhausted continuation must terminate restoration; it must not loop or silently retry.
- Wait for the required extent before restoring focus and scroll. Native BFCache already containing the extent must not request more cards. Native cold Back and HTMX history restore are separate paths. Show detail-to-episode navigation must retain the original Show action, without reopening playback on return.
- Abort restoration on page exit, a new main request or profile change. A late request must not mutate a replaced Library or claim focus in a different browse view. Bounds deliberately limit restoration to 2,000 cards and 100 continuation requests; larger current libraries remain browsable using their normal controls.
