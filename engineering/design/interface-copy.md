# Kinosail interface copy

Use a calm, direct voice. Write short sentences in US English. Use familiar words and sentence case. Keep humor and promotional language out of setup, errors, payments, and recovery. An error states what failed and the next useful action. A button names its action.

Use the same term for the same destination or operation in every client:

| Meaning | Use |
| --- | --- |
| Product and self-hosted service | Kinosail; Kinosail Server |
| Person with server administration access | Owner |
| Person-specific library and progress | Viewer Profile |
| Main destination | Home |
| Series category | Shows |
| Saved titles | My List |
| Resumable video | Continue watching |
| Repeat a failed operation | Try again |
| Leave this device's session | Sign out |
| Search field | Search library |
| Open the library | Browse library |

Use **Subtitles** for timed text tracks. Use **Captions** when a control specifically refers to sound descriptions or SDH. Keep platform names such as Apple TV, AirPlay, Google Cast, and Wear OS where they explain a real capability.

The web apps hold the shared UI translations. Native clients reuse Player's translated message values for matching copy. English remains the fallback when a translation is absent. New native-only copy needs a translation and review before calling that screen fully localized. Do not join translated sentence fragments or translate a media title, server name, URL, or user-provided value.

This guide follows [Apple's interface writing guidance](https://developer.apple.com/design/human-interface-guidelines/writing), [Microsoft's global writing tips](https://learn.microsoft.com/en-us/style-guide/global-communications/writing-tips), and [Google's global audience guidance](https://developers.google.com/style/translation).
