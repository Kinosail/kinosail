# Show me

Choose the smallest visual that makes the important relationship clear:

- pseudocode for logic;
- a call tree for runtime flow;
- a shallow file or component tree for ownership;
- a diff for a proposed change;
- Mermaid for multi-part flow or dependency structure;
- one local HTML artifact for dense layout or interactive comparison.

Include only the calls, files, states, and boundaries needed for the question. Match a product's established visual system when making HTML. Open created artifacts with the available file-opening tool.
