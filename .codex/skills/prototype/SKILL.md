# Prototype

State the question the prototype must answer and choose one mode:

- For logic or state, read [LOGIC.md](LOGIC.md).
- For visual UI, read [UI.md](UI.md).

Keep prototype code clearly marked, easy to run, isolated from production data, and no more polished than the question requires. Use representative state so the result exposes meaningful behavior.

Show or open the result and record the answer. Fold validated decisions into production only when the user requested implementation. Preserve or publish the prototype only when it adds lasting value and that action is authorized.
