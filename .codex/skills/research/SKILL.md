# Research

Answer from authoritative primary sources: official documentation, specifications, source code, papers, or first-party APIs. Trace material claims to the source that owns them and distinguish evidence from inference.

Delegate bounded reading only when it can proceed independently and delegation is available. A repository Markdown note is required when the user asks for one or the findings need durable project context; otherwise return a concise cited answer.

When writing a note, follow the repository's existing research location and format.
