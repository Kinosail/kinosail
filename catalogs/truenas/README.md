# TrueNAS catalog source

The `kinosail/` directory holds the app-specific source for the [TrueNAS Community catalog proposal](https://github.com/truenas/apps/pull/5924). The upstream catalog vendors its rendering library under `templates/library/`; this repository does not duplicate that generated library. Use the upstream catalog package, or use the [Compose install guide](https://kinosail.com/getting-started/platforms/) while the proposal is in review.
